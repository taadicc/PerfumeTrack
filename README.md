# PerfumeTrack

PerfumeTrack is a JavaFX desktop application developed as an academic project to practice Java application development and relational database design.

## Technologies

- Java
- JavaFX
- MySQL
- SQL
- MySQL Workbench

## Project Overview

The project combines a Java desktop application with a MySQL relational database. It includes the application source code, database definition scripts, and resources used to design and manage the database.

## Database Features

The database component includes:

- Database schema creation using DDL
- SQL scripts for inserting data
- SQL views
- Stored procedures
- Database triggers
- A conceptual database model

## Project Structure

- `ProjekatBaze/` — Java application source code and project configuration
- `Pogledi/` — SQL views
- `Procedure/` — stored procedures
- `Trigeri/` — database triggers
- `DDL Skripta.sql` — database schema definition
- `Podaci.sql` — data insertion script
- `PerfumeTrack.mwb` — MySQL Workbench model
- `Konceptualni model.png` — conceptual database model

## Purpose

This project demonstrates practical experience with Java, desktop application development, relational database modeling, and SQL programming.
